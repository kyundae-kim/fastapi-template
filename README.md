# fastapi-template

FastAPI 프로젝트 템플릿입니다.  
`uv` 패키지 매니저 환경에서 동작합니다.

## 빠른 시작

```bash
# 의존성 설치
uv sync

# 개발 서버 실행
uv run fastapi dev
```
